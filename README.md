# BossGate — последовательная разблокировка боссов для TShock

Плагин для **TShock 6.1.0** (Terraria 1.4.5.6, .NET 9).

Боссы на сервере открываются по очереди: раз в N реальных часов (по умолчанию 72 = 3 дня)
становится доступен следующий босс из заданного порядка. Закрытого босса нельзя призвать
никаким способом — ни предметом, ни естественным спавном, ни через читерский клиент.

## Как это работает

Вся логика — **только на сервере**. Клиенту не доверяем нигде:

| Путь призыва | Что делает плагин |
|---|---|
| Предмет призыва (пакет 61 `SpawnBossorInvasion`) | Пакет гасится до обработки — предмет не тратится, игроку возвращается копия предмета и уходит личное сообщение |
| Естественный ночной спавн (Глаз Ктулху, механические боссы) | Перехват в `NpcSetDefaults` — NPC не создаётся вообще |
| Спавн из ивентов, ритуалов (Культист, Лунный Лорд), сегментов (Пожиратель миров) | Все NPC id босса, включая сегменты и части тела, перечислены в конфиге и гасятся так же |
| Обход через сторонние плагины / нестандартные пути | Раз в секунду проходим по `Main.npc` и убираем закрытых боссов до синхронизации |
| Стена Плоти и переход в хардмод | Отдельный флаг `BlockWallOfFleshHardmode`: блокирует выброс Вуду-куклы проводника и откатывает `Main.hardMode`, если он всё-таки включился |

Таймер считает **реальное время в UTC** и тикает, даже когда сервер выключен: в базе хранятся
абсолютные метки времени, при старте плагин догоняет все пропущенные разблокировки.
Состояние лежит в базе TShock (по умолчанию `tshock/tshock.sqlite`, таблица `BossGateState`)
и привязано к **ID мира**, так что несколько миров на одном сервере не мешают друг другу.

## Установка

1. Скачайте `BossGate.dll` из релизов (или соберите сами, см. ниже).
2. Положите в папку `ServerPlugins/` вашего TShock.
3. Запустите сервер — файл `tshock/BossGate.json` создастся сам со значениями по умолчанию.
4. Выдайте админской группе право `bossgate.admin`:

```bash
/group addperm admin bossgate.admin
```

### Сборка из исходников

```bash
dotnet build BossGate/BossGate.csproj -c Release
```

Готовая `BossGate.dll` появится в `BossGate/bin/Release/`.

Если NuGet-пакета `TShock 6.1.0` нет в вашем фиде — откройте `BossGate/BossGate.csproj`,
закомментируйте блок с `PackageReference` и раскомментируйте блок с `Reference` на DLL,
затем соберите с путём к серверу:

```bash
dotnet build BossGate/BossGate.csproj -c Release -p:TShockPath=C:\TShock
```

## Конфиг — `tshock/BossGate.json`

| Поле | По умолчанию | Что делает |
|---|---|---|
| `Enabled` | `true` | Полностью включает/выключает ограничения |
| `UnlockIntervalHours` | `72` | Через сколько часов реального времени открывается следующий босс |
| `BlockWallOfFleshHardmode` | `true` | Дополнительная защита от преждевременного хардмода (см. таблицу выше) |
| `AnnounceHourBefore` | `true` | Напоминание в чат за час до открытия |
| `LogBlockedAttempts` | `true` | Писать в консоль каждую заблокированную попытку |
| `RequireUsePermission` | `false` | Требовать право `bossgate.use` для `/bosses` и `/bosstime` |
| `Bosses` | ванильная прогрессия | Порядок боссов, см. ниже |
| `Messages` | русские тексты | Все сообщения плагина |

### Порядок боссов

Порядок в массиве `Bosses` = порядок открытия. Первый босс доступен сразу при старте отсчёта.
Одна запись может объединять несколько боссов — тогда они открываются одновременно
(так сделано для Пожирателя миров / Мозга Ктулху и для трёх механических боссов).

```jsonc
{
  "Key": "eow_boc",
  "DisplayName": "Пожиратель миров / Мозг Ктулху",
  // все NPC id, включая сегменты червя и криперов
  "NpcIds": [13, 14, 15, 266, 267],
  // "id NPC босса": "id предмета призыва" — предмет вернётся игроку при блокировке
  "SummonItems": { "13": 70, "266": 1331 }
}
```

Прогрессия по умолчанию:

1. Королевский слизень
2. Глаз Ктулху
3. Пожиратель миров / Мозг Ктулху
4. Пчелиная матка
5. Скелетрон
6. Лютый олень
7. Стена Плоти
8. Королева слизней
9. Механические боссы (Близнецы / Уничтожитель / Скелетрон Прайм)
10. Плантера
11. Голем
12. Герцог Рыброн
13. Императрица Света
14. Лунатик-культист
15. Лунный Лорд

### Сообщения

В `Messages` поддерживаются подстановки `{0}`, `{1}` (что именно — написано в комментариях
исходника `BossGateConfig.cs`) и цветовые теги Terraria вида `[c/ff5555:текст]`.
Кривой шаблон не уронит плагин — сообщение просто отправится как есть.

## Команды

| Команда | Право | Что делает |
|---|---|---|
| `/bosses` | — (или `bossgate.use`) | Список боссов: открытые и закрытые, плюс время до следующего |
| `/bosstime` | — (или `bossgate.use`) | Сколько осталось до следующей разблокировки |
| `/bossunlock` | `bossgate.admin` | Открыть следующего босса вручную (таймер перезапускается) |
| `/bosslock <n>` | `bossgate.admin` | Откатить счётчик на `n` боссов назад |
| `/bossreload` | `bossgate.admin` | Перезагрузить конфиг без рестарта сервера |

Права — обычные строки разрешений TShock, поэтому работают вместе с Permissions++
и любым другим менеджером групп.

## Объявления

* При разблокировке — broadcast всем онлайн-игрокам с названием нового босса.
* За час до открытия — напоминание в чат (`AnnounceHourBefore`).
* Разблокировки, случившиеся пока сервер был выключен, применяются молча и пишутся в лог.

## Устойчивость к ошибкам

* Битый или отсутствующий JSON → плагин пишет причину в консоль и работает на значениях по умолчанию.
* Некорректные значения (`UnlockIntervalHours <= 0`, боссы без `NpcIds`, отсутствующая секция `Messages`)
  чинятся автоматически при загрузке.
* Ошибка инициализации БД → ограничения **выключаются**, сервер продолжает работать.
* Каждый хук и разбор пакета обёрнуты в `try/catch` — плагин не роняет сервер.
